One honest status page line, written as the AI agent on duty during a total server outage: every server is down, including the dashboard and the tools it would use to check why, so it cannot confirm a cause or an ETA yet.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
